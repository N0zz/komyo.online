TUBE RACER — MODE CARD PREVIEWS

Three ways to tell the four modes apart, each drawn at the sizes the kit actually uses: 92px is the desktop card, 40px is the landscape split (640×360) — that one is the real test, because at 40px a decal is a smudge. 120px is the canvas backing store, shown for detail only.

A · SHIPS TODAY same tunnel, one coloured arc

All four are the same concentric rings with an arc in a different place and colour. At 40px the four are effectively one image — which is the same trap the palette comment in the game warns about: two components that read the same are the worst bug this game can have.

B · THE TUBE BEHAVES DIFFERENTLY no decals

Instead of stamping an icon on a shared picture, each mode changes what the pipe is doing: sprint becomes a dial with a finish line, redline runs hot and flares, cruise goes calm and wide, classic keeps the neutral pipe with a gap to thread. Silhouette and colour carry it, so it survives 40px.

C · B PLUS A GLYPH your suggestion, on top of B

Same as B with one small mark in the corner — clock, boost chevrons, easing wave, notched ring. The glyph is the tiebreaker for a player who has never seen the cards; the tube treatment is what still works when the glyph is 6px across. Note classic gets one too, or it becomes "the one with no icon".

IN CONTEXT variant C at the real desktop card size

My pick: C, weighted to B — the tube treatment does the work, the glyph is insurance. B alone is defensible and cheaper. A is what ships today and should not.
Cost either way is one function (pvTube) in games/tube-racer/index.html — the four mode cards already call it with the mode name, so nothing else in the menu changes.
